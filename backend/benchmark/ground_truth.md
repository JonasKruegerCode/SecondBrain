# Ingestion Benchmark — Ground Truth

25 klar abgegrenzte Fakten, thematisch gemischt (Personen, Technologie, Orte, Ereignisse,
Relationen). Jeder Fakt ist genau einer Zeile zugeordnet und trägt eine ID (F01–F25).
Der Benchmark-Runner prüft, ob jeder Fakt als eigenständige Operation im Plan erscheint.

---

## Fakten

F01: Marie Curie wurde 1867 in Warschau geboren und starb 1934 in Frankreich.
F02: Marie Curie erhielt 1903 den Nobelpreis für Physik und 1911 den Nobelpreis für Chemie.
F03: Das Element Polonium wurde von Marie Curie entdeckt und nach ihrem Heimatland benannt.
F04: Das Element Radium wurde ebenfalls von Marie Curie und Pierre Curie entdeckt.
F05: Pierre Curie war der Ehemann von Marie Curie und ihr wissenschaftlicher Partner.
F06: Das Python-Framework LangGraph ermöglicht die Erstellung zustandsbasierter KI-Agenten als gerichtete Graphen.
F07: LangGraph unterstützt zyklische Graphen, was Retry-Schleifen und bedingte Kanten ermöglicht.
F08: Qdrant ist eine Vektordatenbank, die für Nearest-Neighbour-Suche optimiert ist.
F09: Qdrant unterstützt skalierbares Filtering über Payload-Felder direkt bei der Vektorsuche.
F10: Neo4j ist eine Graphdatenbank, die Daten als Knoten und Kanten mit Eigenschaften speichert.
F11: Die Cypher-Abfragesprache wird für Neo4j verwendet, ähnlich wie SQL für relationale Datenbanken.
F12: OpenRouter ist ein API-Gateway, das Zugang zu verschiedenen LLM-Providern über eine einheitliche Schnittstelle bietet.
F13: OpenRouter unterstützt automatisches Model-Routing basierend auf Verfügbarkeit und Kosten.
F14: Das Brandenburger Tor liegt in Berlin und wurde 1791 fertiggestellt.
F15: Der Eiffelturm in Paris wurde 1889 anlässlich der Weltausstellung erbaut.
F16: Der Eiffelturm ist 330 Meter hoch (inklusive Antenne).
F17: Gustave Eiffel entwarf den Eiffelturm und leitete den Bau.
F18: Die Relativitätstheorie wurde von Albert Einstein entwickelt, die spezielle 1905 und die allgemeine 1915.
F19: Albert Einstein erhielt 1921 den Nobelpreis für Physik, jedoch für den photoelektrischen Effekt, nicht für die Relativitätstheorie.
F20: Das Model Context Protocol (MCP) ist ein offener Standard von Anthropic zur Verbindung von KI-Systemen mit externen Tools.
F21: MCP verwendet einen Client-Server-Ansatz, bei dem der KI-Client Tools über einen standardisierten JSON-RPC-Kanal aufruft.
F22: Git ist ein verteiltes Versionskontrollsystem, das 2005 von Linus Torvalds entwickelt wurde.
F23: Redis kann als In-Memory-Datenbank, Message Broker und Cache eingesetzt werden.
F24: Celery ist ein asynchrones Task-Queue-System für Python, das häufig mit Redis als Broker betrieben wird.
F25: GraphRAG kombiniert Vektorsuche mit Graph-Traversal, um bei der Retrieval-Phase strukturelle Beziehungen zwischen Dokumenten zu nutzen.
