# SecondBrain website prototype — Orbit Bento

Static project website prototype. This variant is **Orbit Bento**.

There is no build step. Open `website/index.html` in a browser, or serve the folder:

```bash
python3 -m http.server
```

Run that command from `website/` so the relative asset paths resolve.

This prototype is not deployed. The one-line install command on the page points at `main` (`install.sh` on the `main` branch). That command only works after the 2.0 release. Screenshots in `assets/` come from the repository’s fictional demo data.
